# Glossar & Tag-Liste

Feste Tag-Liste für die gesamte Vault. Neue Tags nur über den Gehirn-Admin-Chat hinzufügen.

## Tag-Namespaces

### typ/
Klassifiziert die Art der Datei.

- `typ/status` — Statusübersicht, Dashboard
- `typ/regel` — Regeln, Richtlinien
- `typ/setup` — Technische Einrichtung
- `typ/wissen` — Wissensdokumentation
- `typ/fazit` — Chat-Fazit, Session-Export
- `typ/vorlage` — Template, Muster
- `typ/guide` — Anleitung, How-To

### status/
Aktualitätsstatus der Datei.

- `status/aktuell` — Aktiv gepflegt
- `status/veraltet` — Markiert zum Löschen (nach 6 Monaten)

### projekt/
Projektzugehörigkeit.

- `projekt/nestbau` — Household-Management-App
- `projekt/github-automation` — GitHub-Repo-Tool
- `projekt/primarlehrer-studium` — Primarlehrer-Ausbildung

### bereich/
Fachbereich innerhalb eines Projekts.

- `bereich/design` — UI, CSS, Design-System
- `bereich/firebase` — Firebase, Firestore, Auth
- `bereich/kalender` — Kalender-Features
- `bereich/kochbuch` — Rezepte, Koch-Features
- `bereich/security` — Sicherheit, Credentials, Audit
- `bereich/auth` — Authentifizierung, Login

## Begriffe

- **CEO-Chat** — Koordinierender Chat eines Projekts, vergibt Aufgaben
- **Worker/Bot** — Ausführender Chat, arbeitet an einer Aufgabe
- **Fazit** — Zusammenfassung einer Chat-Session, gespeichert in FAZITE/
- **Gehirn-Admin** — Permanenter Chat für Vault-Organisation
- **Vault** — Das Obsidian-Repository als Ganzes
- **kebab-case** — kleinbuchstaben-mit-bindestrichen
