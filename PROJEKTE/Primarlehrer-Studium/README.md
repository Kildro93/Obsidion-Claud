# Primarlehrer-Studium: Projekt-Zentrale

Infrastruktur für automatisierte Prüfungs-Generierung, Englisch-Unterricht, Fortschritts-Tracking.

## Chat: "Prüfung Studium"

Interaktiver Lern-Assistant mit:
- **Prüfungs-Generierung** aus OneNote-Inhalten
- **Englisch Grundgrammatik** (CEFR A1→B1, strukturiert)
- **Fortschritts-Memory** (welche Kapitel beherrscht)
- **Spaced Repetition (SRS)** (adaptive Abfrag-Häufigkeit)
- **Performance-Tracking** (Genauigkeit, Zeit, Trends)
- **Multi-Level-Fragen** (Basis/Mittel/Fortgeschritten)
- **Prüfungs-Export** (PDF/druckbar)
