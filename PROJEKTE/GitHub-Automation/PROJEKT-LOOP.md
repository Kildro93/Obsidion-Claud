# PROJEKT-LOOP: GitHub-Automation

## Was ist das?

Ein Tool, kein Bot-Loop-Projekt. `github-automation.html` ist eine lokale Browser-App: Projekt-Notiz aus `Projekte/` reinkopieren → sie legt via GitHub-API ein Repo an (Name, Beschreibung, Topics, README, .gitignore, LICENSE). Committet keinen Code.

## Dateien
- `github-automation.html` – die App (lokal öffnen, Token + Username `Kildro93` eintragen)
- `_INDEX.md` – Liste der verwalteten Projekte
- `GitHub-Naming-Regeln.md` – Naming-Konventionen (kebab-case, max 30 Zeichen, Topic `claude-automation`)
- `QUICK-START.md` – 3-Schritte-Anleitung
- `PAT-Setup.md` – Token-Handling (Token nur im Browser-localStorage, nie in Dateien)
- `Projekte/` – Projekt-Vorlagen (`template.md`, `nestbau.md`)

## Kein CEO/Bot-Workflow

Dieses "Projekt" wird direkt genutzt, nicht über einen Loop. Wenn daran entwickelt wird (an der HTML-App selbst), gelten die normalen [[Regeln]].
