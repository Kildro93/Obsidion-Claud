# ⚡ Quick-Start Guide

**Starte jetzt mit GitHub Automation!**

---

## 🎯 3 Schritte zum Starten

### Schritt 1: GitHub PAT (5 Minuten)

1. Gehe zu: https://github.com/settings/tokens?type=beta
2. **"Generate new token (beta)"** klicken
3. Ausfüllen:
   - Name: `Claude-Automation`
   - Expiration: `90 days`
4. Permissions: ✅ **repository** + **user**
5. **Generate** → Token **kopieren** (wird nur einmal angezeigt!)

---

### Schritt 2: App öffnen (1 Minute)

1. Doppelklick: **`github-automation.html`**
2. Browser öffnet sich automatisch

---

### Schritt 3: Token eingeben (2 Minuten)

1. In der App oben:
   - **Token einfügen** (von Schritt 1)
   - **Username eintragen**: `Kildro93`
2. **"✅ Konfiguration speichern"** klicken

---

## 🚀 Erstes Projekt erstellen

1. Öffne: **`Projekte/nestbau.md`**
2. Markiere alles: `Ctrl+A`
3. Kopiere: `Ctrl+C`
4. In der App: Paste in **"Projekt-Daten"**
5. Klick: **"📦 Projekte erstellen"**

**Fertig!** Schau auf GitHub nach dem neuen Repo 🎉

## 🔧 Häufige Aufgaben

### Neues Projekt erstellen

1. Kopiere: `Projekte/template.md`
2. Benenne um: `Projekte/mein-projekt.md`
3. Fülle die Felder aus
4. Copy-Paste in die App → **"Projekte erstellen"**

### Projekt aktualisieren

1. Bearbeite: `Projekte/mein-projekt.md`
2. Copy-Paste in die App
3. Klick: **"🔄 Mit GitHub synchen"**

### Alle Projekte sehen

- Öffne: **`_INDEX.md`**

### Regeln & Standards checken

- Öffne: **`GitHub-Naming-Regeln.md`**

---

## 🚨 Probleme?

### "Invalid token"
→ Neuen Token generieren (Schritt 1 wiederholen)

### "Repository already exists"
→ Repo-Name in `Projekte/*.md` ändern

### "Logs zeigen Fehler"
→ Schau in die App → rotes Log = Problem

---

## 📌 Wichtig zu wissen

✅ **Token ist sicher** — wird nur lokal im Browser gespeichert
✅ **Kann offline arbeiten** — App braucht keinen Server
✅ **Keine Credentials online** — Alles bleibt lokal
